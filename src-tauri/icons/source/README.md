# Icons

Omega Zap uses the Omega family mark (a geometric Ω) in the `zap` palette: teal on dark ink. The
SVGs here are generated by the Omega brand repo; change the shape or the palette there, not here.

- `omega-zap.svg`: the app icon (rounded square, used for the taskbar, notifications and installers).
- `omega-zap-tray.svg`: the bare mark with no background, for the system tray.
- `omega-zap-dev.svg`: the app icon with a DEV band across the bottom, for debug builds.

## Turning the SVGs into this app's icons

Needs `rsvg-convert` (librsvg). The DEV band uses Noto Sans Black, so render it where that font is installed.

```sh
S=src-tauri/icons/source
# Every size Tauri bundles (PNG, .ico, .icns), from a 1024 px render
rsvg-convert -w 1024 -h 1024 $S/omega-zap.svg -o /tmp/omega-zap.png
pnpm tauri icon /tmp/omega-zap.png
rm -rf src-tauri/icons/android src-tauri/icons/ios   # desktop only

# The tray mark (the app draws the unread badge on it)
rsvg-convert -w 64 -h 64 $S/omega-zap-tray.svg -o src-tauri/icons/tray.png

# The dev build's icon (window, taskbar and desktop entry)
for n in 32 128 256; do rsvg-convert -w $n -h $n $S/omega-zap-dev.svg -o src-tauri/icons/dev/${n}x${n}.png; done
```

The app embeds the PNGs at build time, so rebuild afterwards. On Linux it registers its desktop
entry with an icon name that includes a hash of the icon, so the desktop shows a changed icon
straight away instead of a cached one.
